# 日日有进

行测、申论每日打卡与小院养成工作台。MIT 开源，手机和电脑均可使用。

在线使用：https://Yueee-0305.github.io/exam-daily/

## 功能

- 每科每日最多五项任务，可自主编辑；课程优先级：判断、资料、数量、言语。
- 行测 170 课时、申论 34 课时，课程进度分别统计。
- 专注倒计时 20 / 40 / 60 分钟，以及独立刷题秒表与成绩记录。
- 树苗盲盒、猫咪撒娇／挥爪／伸懒腰／跳跃互动、可静音的合成猫叫、任务奖励与六个成长阶段。
- 每日九点页面提醒与手机日历提醒导出（设备当地时间）。
- 复盘复制、CSV 导出、完整 JSON 备份与导入。
- 苹果 Safari 添加到主屏幕，作为个人网页应用使用。

## 数据与隐私

这是公开的静态版本，无需登录。记录仅保存在当前浏览器的 localStorage，不会上传到 GitHub，也不会自动跨设备同步。清理站点数据会清除记录，请定期在“使用设置”导出完整备份。导入备份会替换当前记录。

Notion 按钮打开使用者自己的笔记库；复盘可以复制粘贴，尚未接入自动同步。支持页面打开时的每日九点提醒，以及每日九点日历提醒文件导出。静态网页关闭后不会自行推送，请导入系统日历并启用通知，或在苹果提醒事项中创建每日九点提醒。没有离线安装保证或 iOS 小组件。

仓库不包含个人打卡数据、私人 Notion 页面、访问令牌或原部署身份信息。

## 本地开发

需要 Node.js 22.13+。

```sh
npm install
npm run dev
npm run build
npm run preview
```

源码位于 `src/`，日程位于 `src/lib/plan.json`。考试日期按原计划预设，仅用于个人排期，请以官方公告为准。课时分类可按实际课程目录调整。仓库不提供课程视频、题库或付费教材。

## 发布到 GitHub Pages

运行 `npm run build`，提交生成的 `docs/`，在 Settings → Pages 选择 Deploy from a branch、main、/docs。修改源码后重新构建并提交。配置使用相对资源路径，支持项目子目录部署。

## 套卷成绩表

从侧栏“套卷成绩”或工作台“打开成绩表”进入。行测、申论分科记录日期、套卷名称、轮次、总分和各模块单项。视图支持得分／满分、正确率、用时，单项可标为重点复盘。可新增模块、建立空白二刷行、撤销删除、筛选与导出 CSV。

编辑完成点击“保存表格”。空白值不作为零分，单项得分率只在得分和满分都填写后计算，正确率须单独录入。记录存放在主备份的 `values["scorebook.v1"]` 中，随完整 JSON 备份导入导出；未保存内容单独暂存为本机草稿。参考图片仅用于布局，不提供示例成绩。

套卷成绩的“复盘”视图可在各模块下按题号记录考点要点、错因与改法；CSV包含题目复盘。整卷备注和工作台当天复盘均可添加Word原件（.doc/.docx，单份500KB，每处5份），点击文件名下载。成绩页附件须随表格保存，当天复盘附件自动保存。附件为浏览器本地记录，不上传GitHub；完整JSON备份包括附件，CSV不包含原件。套卷表含附件上限约2.8MB，存储不足会提示失败；应定期备份与下载归档。

### 桌面Excel同步

套卷成绩页展开“与桌面 Excel 同步”。先保存网页表格，按科目下载“成绩同步.csv”；桌面Chrome/Edge可通过系统文件选择器关联这份CSV，点击“写回 Excel 文件”更新同一文件。Excel编辑后以CSV UTF-8格式保存并关闭文件，再点击“读取 Excel 修改”，确认并保存网页表格。刷新或离开成绩页需重新关联。其他浏览器支持手动下载/导入同步CSV。

此功能是用户触发的双向文件交换，不是后台实时同步，不直接支持.xlsx、公式或排版。每科单独文件，保留表头与记录编号（新行编号留空），新增模块后需重新导出模板。导入按编号新增/更新，CSV删行不删除网页记录；导入覆盖成绩与复盘文字，保留网页Word附件。写回前比较上次关联/读取时的文件内容，发现外部修改则停止；两端同时修改时应先下载网页副本再人工合并。文件受浏览器权限和Excel占用影响，错误时应关闭Excel并重试。

### 橘子桌面悬浮窗

电脑页面顶部“最小化为橘子”优先调用Document Picture-in-Picture，显示置顶的2D橘子，可拖动窗口标题栏调整位置，点击橘子返回原工作台。复用原有猫咪SVG，保持比例、轻微走动和悬停互动，点击遵循猫叫开关。工作台保留在原页面，悬浮窗口关闭不会删除数据。浏览器不支持时回退普通弹窗（需要允许弹窗，置顶需系统工具）。浏览器窗口具有不透明背景和系统边框；此功能不接管操作系统最小化按钮，也不能把网页做成透明无框桌宠。请保留工作台标签页；关闭原标签页会结束其画中画窗口。

## Windows 桌面客户端

`desktop/` 提供Electron桌面版，发布页下载Windows x64便携EXE。工作台仍保留正常窗口；点击“最小化为橘子”或系统最小化后，工作台隐藏，仅显示透明、无边框、置顶的橘子2D形象。点击恢复工作台，按住拖动调整位置，右键可返回或退出。关闭工作台即退出应用。

桌面客户端使用独立本地数据，首次使用：网页“使用设置→导出完整备份”，客户端“使用设置→导入备份”。保存浏览器备份后再迁移；网页与客户端不会自动同步。客户端内置工作台资源，可离线记录，外链和联网服务需网络。程序未签名；当前构建为Windows x64，不是macOS或ARM安装包。

构建：复制`docs/`到`desktop/app/`，在`desktop`执行`npm install`及`npm run dist:win`。GitHub工作流`Windows desktop client`构建并将便携版上传至`desktop-v0.2.0`Release。桌面更新需下载新版，当前不提供自动更新。
